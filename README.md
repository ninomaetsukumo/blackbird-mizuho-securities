# Project Blackbird — Mizuho Securities

A public, privacy-minimised OSINT case study by **Ninomae Tsukumo** examining the public-record environment around the 2026 Securities and Exchange Surveillance Commission (SESC) investigation of Mizuho Securities.

## Publication

**The Mizuho Conspiracy File — Public Edition**

This repository contains the publication-safe edition of the Project Blackbird Mizuho Securities case. It focuses on institutional controls, historical information-control matters, verified transaction environments, organisational chronology, competing explanations, negative findings, and the limits of public-source research.

[Read the full public report](REPORT.md)

## Research boundary

This publication does **not** establish a conspiracy, insider-trading scheme, criminal agreement, regulatory violation, or misconduct by any named person or organisation.

The public edition deliberately minimises personal identifiers. Individual names are omitted where a role-level description is sufficient to understand the analytical point.

## Evidence model

Project Blackbird separates:

- **Verified Fact**
- **Reported Information**
- **Analytical Judgment**
- **Hypothesis**
- **Alternative Explanation**
- **Negative Finding**
- **Unknown**

Primary and official sources are preferred where available. A documented association does not imply misconduct, and absence of public evidence is not treated as evidence of concealment.
